What it does

Sessions stop being terminals. They become objects.

Drag, label, color, tag, and rearrange your Claude Code sessions across a free-form canvas. Every session lives in tmux so it survives Grove itself — pick it up in any terminal, drop it back in.

Spatial workspace

Free-position panels on an infinite canvas. Pan, zoom, drag, resize, fit-all. A mini-map shows everything at once.

Drag in. Drag out.

Sessions live in tmux. Drag any tmux session into Grove. Detach to send it back to your terminal — same conversation, same scrollback.

Label, tag, color

Eight warm session colors. Reusable tags with filter-by-tag. Inline rename. Sidebar reorder. Persisted across launches.

Real terminals

xterm.js with WebGL rendering, full ANSI color, scrollback. Dark interiors in every theme — devs expect that.

Cmd+K everything

Raycast-style command palette. New session, focus by name, change theme, fit canvas, kill, settings — all keyboard.

Eight themes

Grove Warm, Grove Dark, Paper, Terminal Black, Linear Compact, plus ChatGPT and Gemini tributes. Custom theme editor included.

Requirements

One small dependency.

Grove uses tmux as the session broker — it's what makes sessions portable in and out of Grove. Every modern dev machine should have tmux. If yours doesn't, it's one command away.
